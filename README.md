🤖 مسیح هکرینگ | بات‌ساز 

بات‌ساز تلگرام با رابط فارسی و دکمه‌های مدیریتی.

امکانات فعلی

- نمایش منوی اصلی
- دکمه ساخت ربات جدید
- بخش ربات‌های من
- راهنمای استفاده
- دریافت پیام‌ها و پاسخ‌گویی خودکار

نصب کتابخانه‌ها

pip install -r requirements.txt

تنظیم توکن

در تنظیمات محیطی هاست، متغیر زیر را بساز:

"TELEGRAM_BOT_TOKEN"

مقدار آن باید توکن ربات اصلی باشد که از BotFather گرفته‌ای.

اجرای برنامه

python main.py

نکته

این نسخه اولیه است. ساخت واقعی ربات‌های کاربران، ذخیره‌سازی امن و مدیریت ربات‌ها باید در مراحل بعدی اضافه شود.

توکن ربات را در کد یا مخزن عمومی گیت‌هاب قرار نده.
